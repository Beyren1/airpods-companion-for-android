# Pods Companion for Android

Неофициальное приложение-компаньон для беспроводных наушников Apple на Android.
Не связано с Apple Inc.; AirPods является товарным знаком Apple Inc. и используется
только для указания совместимости.

- План и оценка реализуемости: [docs/01-plan-i-realizuemost.md](docs/01-plan-i-realizuemost.md)
- Структура проекта: [docs/02-struktura-proekta.md](docs/02-struktura-proekta.md)

## Сборка

Откройте папку в Android Studio или выполните `./gradlew assembleDebug`.
Unit-тесты протокола: `./gradlew :protocol-aap:test`.
