# Pods Companion для Mac

Значок в строке меню, который переключает AirPods между Mac и Android-телефоном с приложением
Pods Companion — так же, как iPhone и Mac переключают их между собой. Говорит с телефоном на том же
«языке», что программа для Windows, поэтому телефон видит Mac как ещё один компьютер.

macOS сама умеет почти всё остальное для AirPods (заряд, режимы, датчик уха, пауза при снятии), поэтому
приложение занимается только переключением.

## Что умеет

- **На Mac само**: включил звук на Mac, наушники надеты (по BLE-рекламе AirPods) — Mac просит телефон
  отпустить их и подключает к себе.
- **На телефон само**: включил звук на телефоне — телефон просит Mac отпустить наушники и забирает их.
- **Пауза, когда наушники ушли от Mac**, чтобы музыка не заиграла из динамиков.
- Кнопки «Подключить к Mac» и «Отдать телефону» в меню. Вторая отключает наушники и 8 секунд
  рассылает по Wi-Fi сигнал «забери наушники» (UDP, порт 47820).
- **Режимы шумоподавления через телефон**, пока наушники у телефона.
- Точный заряд от телефона, пока наушники у него; иначе заряд из рекламы (с шагом 10%). Цифра у значка.
- **Звонок на Mac**: пока микрофон занят, телефон не забирает наушники сам.
- Кнопка «⇄» в виджете на телефоне перекидывает наушники и на Mac.
- Запуск при входе, журнал соединения (меню → «Скопировать журнал соединения»).

## Как это устроено

- Сопряжённые наушники, подключение и отключение — IOBluetooth (`openConnection` / `closeConnection`),
  те же вызовы, что у пункта «Подключить» в настройках Bluetooth.
- Надеты ли наушники — BLE-реклама Proximity Pairing через CoreBluetooth (тот же разбор, что на телефоне).
- «Звук начался» — CoreAudio: устройство вывода по умолчанию работает 2 секунды подряд (короткие
  звуки уведомлений не считаются). «Звонок» — так же для микрофона.
- Пауза — команда MediaRemote; если звук всё ещё идёт и дано разрешение «Универсальный доступ», —
  клавиша ⏯.
- Связь с телефоном — UDP в домашней сети, протокол `PCLINK 1 …` (см. `Sources/PodsCore/LinkMessage.swift`).
  В интернет ничего не отправляется.
- Программа для Windows ещё и рассылает сигнал «забери» Bluetooth-рекламой; macOS не даёт программам
  рассылать такие данные, поэтому Mac шлёт его только по Wi-Fi.

## Сборка

Собирается в GitHub Actions (`.github/workflows/macos.yml`), результат — артефакт `PodsCompanion-mac`
с `PodsCompanion-mac.dmg` (универсальная сборка: Apple Silicon и Intel, macOS 13+).
Локально на Mac: `cd macos && swift test && scripts/build-app.sh`.

- `Sources/PodsCore` — чистая логика: разбор рекламы, сообщения связи, сигнал телефону. Тесты — `Tests/`.
- `Sources/PodsCompanionMac` — приложение: Bluetooth, звук, сеть, меню.

Подпись ad-hoc (без платного аккаунта Apple Developer), поэтому при первом запуске macOS предупреждает,
что не может проверить разработчика. Открыть: Системные настройки → Конфиденциальность и безопасность →
внизу «Всё равно открыть».
