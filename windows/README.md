# Pods Companion для Windows

Приложение в трее для AirPods и Beats на Windows 10/11: заряд наушников и кейса, датчик уха
и переключение между телефоном и ПК, похожее на iPhone и Mac.

## Что умеет

- Заряд левого, правого и кейса (у AirPods Max одно значение) в окне и в подсказке значка в трее.
- Пауза, когда снял наушник, и продолжение, когда надел обратно (Spotify, браузеры, плееры).
- **Переключение на ПК само**: включил звук на ПК, наушники надеты — ПК забирает их у телефона.
- **Переключение на телефон само**: включил звук на телефоне — телефон забирает наушники у ПК
  (нужна новая версия приложения для Android с фоновым режимом).
- Пауза, когда наушники ушли к телефону, чтобы звук не пошёл в колонки.
- Кнопки «Подключить к ПК» и «Отдать телефону». Вторая отключает наушники от ПК и 8 секунд
  рассылает сигнал «забери наушники» сразу двумя путями: по Bluetooth и по домашней сети (UDP, порт 47820).
  Телефон забирает наушники по первому дошедшему.
- **Связь с приложением на телефоне** по домашней сети: ПК и телефон знают друг о друге и показывают,
  где наушники. Когда телефон забирает наушники, ПК сразу их отпускает; когда ПК забирает, телефон
  заранее ставит музыку на паузу. При первом запуске Windows спросит доступ к сети: нужно разрешить.
- **Режимы шумоподавления через телефон**, пока наушники у телефона: кнопки режимов в окне ПК.
  Когда наушники у ПК, кнопок нет: Windows сама не умеет менять режим (нужен драйвер ядра с подписью
  Microsoft), а если телефон в это время обратится к наушникам, AirPods Max уходят с ПК.
- **Точный заряд от телефона**, когда наушники у телефона (из канала AAP, а не из рекламы).
- **Ctrl+Alt+P** — перекинуть наушники между ПК и телефоном из любой программы.
- **Несколько ПК**: наушники уходят туда, где включили звук; ПК просят друг друга отпустить их.
- **Обновление одной кнопкой**: когда на GitHub выходит новая версия, в окне появляется кнопка
  «Обновить до версии …».
- Запуск вместе с Windows.

## Установка

`PodsCompanion-Setup.exe`: ставит программу для текущего пользователя (права администратора не нужны),
добавляет ярлык в меню «Пуск» и по желанию — автозапуск. Удаление — «Параметры → Приложения».
Можно и без установки: просто запустить `PodsCompanion.exe`.

## Как это устроено

- Заряд и датчик уха читаются из BLE-рекламы, которую AirPods рассылают всем рядом
  (`BluetoothLEAdvertisementWatcher`). Подключаться к наушникам для этого не нужно.
- Подключение и отключение — те же команды, что у кнопок в параметрах Bluetooth Windows
  (`KSPROPERTY_ONESHOT_RECONNECT/DISCONNECT` звукового драйвера Bluetooth). Без драйверов и прав администратора.
- Звук на ПК узнаём через системные медиаэлементы Windows (`GlobalSystemMediaTransportControlsSessionManager`).

## Сборка

Собирается в GitHub Actions (`.github/workflows/windows.yml`): один `PodsCompanion.exe`, .NET ставить не нужно,
и установщик `PodsCompanion-Setup.exe` (Inno Setup, `installer/PodsCompanion.iss`).
Выпуск новой версии: поднять `<Version>` в `src/PodsCompanion.App/PodsCompanion.App.csproj`, после слияния
запустить Actions → Windows CI → Run workflow с галочкой «Create draft release» и опубликовать черновик
`windows-v<версия>` — тогда программы у пользователей предложат обновиться.
Локально: `dotnet test windows/tests/PodsCompanion.Core.Tests` и
`dotnet publish windows/src/PodsCompanion.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`.

- `src/PodsCompanion.Core` — вся логика: разбор рекламы, Bluetooth, медиа, автопереключение.
- `src/PodsCompanion.App` — окно над треем (WPF, оформление Windows 11) и значок в трее.
- `tests/PodsCompanion.Core.Tests` — проверки на тех же реальных пакетах, что в Android-приложении.
